# Reel Studio icons

A solid ink (`#1d1b18`) 9:16 phone, the shape of a Reel, sits on a warm off-white (`#f7f5f1`) squircle plate. A coral (`#e8603c`) play triangle on the phone says "video", and a small coral sparkle at its corner says "finished for you". There is no text and there are no gradients, so it still reads at 16 px. The mac master follows the Big Sur+ grid (1024 canvas, 824 px plate, soft shadow). The Windows `.ico` uses the same design with no shadow, a slightly larger plate and a stronger edge line so it holds up on light taskbars. Files: `icon.svg` (source), `icon.png` (1024), `icon.icns` (16-1024 including @2x), `icon.ico` (16, 24, 32, 48, 64, 128, 256). To regenerate, run `python -m venv .venv`, then `.venv/bin/pip install pillow resvg-py`, then `.venv/bin/python packaging/icons/build_icons.py`. The design lives in `make_svg()` in that script, and it also writes a throwaway `_preview/` folder (gitignored) with 64/32/16 px renders to check.
